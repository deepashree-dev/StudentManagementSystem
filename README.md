                Student Management System

## Project Description
A simple Student Management System developed using Java. This project helps manage student information efficiently.

## Features
- Add student details
- Display student information
- Store student ID, name, age, and course
- Manage student records

## Technologies Used
- Java
- VS Code
- Git & GitHub

## Project Structure
- Student.java – Contains student details and methods.
- Main.java – Runs the student management program.
